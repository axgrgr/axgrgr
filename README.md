## Proyectos Destacados

### [HuronCheck] (yo no puse el name)
Sistema de control de asistencia biométrico y mediante códigos QR, diseñado para automatizar y optimizar el registro de acceso a laboratorios de cóomputo con reportes en tiempo real. El proyecto integra una API que conecta el sistema central con una aplicación móvil creada para el escaneo de los códigos QR.

### [Ventitax] (en prueba Alpha cerrada en Play Store)
Es una app de marketplace local diseñada especialmente para mujeres emprendedoras mexicanas, después verán publicidad en redes sociales.
